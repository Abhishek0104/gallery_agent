# Path Catalog — v0 (for review)

Generated by `generate_catalog.py` from type rules + plausibility rules. **86 paths.**
All paths reviewed and set to `keep`. Weights stay 1.0 until after the first generation.
Edit rules in the script and regenerate rather than hand-editing paths where possible.

## Notation
- `search→r1` : tool call producing handle r1
- `effect(r1)→r2` : tool consuming r1, producing r2
- `[select](r1)→r2` : user selection event (not a tool call) from what was just shown
- `r0` : selection present when the conversation starts
- `calls` counts tool calls only (selections excluded)

## Type rules (hard)
1. A tool that consumes a handle can only run after something produced one (search, ask_gallery, selection, collage, effect).
2. `delete_images` kills its handle and is **terminal** — nothing follows a delete.
   (So delete can never come before an effect; effect → delete is valid, e.g. user didn't like the result.)
3. `make_collage` needs a multi-image set — no collage of a collage.
4. Selection only from a multi-image set, only from what was just shown.

## Plausibility rules (soft — review these)
5. With an initial selection, the first action must use it.
6. `ask_gallery` only as the opening step, followed by at most one action.
7. Search refinement (`search → search`) only directly after a search, at most once.
8. Actions apply to the newest handle.
9. No repeating the same tool on the same handle; at most one `apply_effect` per path.
10. Nothing follows `move_to_album`.
11. At most one selection event per path; a selection must lead to an action.
12. Max 4 tool calls.

## Not in the catalog (separate axes, applied at sampling time)
- **Outcomes:** search count bucket (0 / 1 / few / over collage max), delete confirm vs cancel, album exists vs new.
  An early outcome can truncate a path (e.g. search returns 0 → chain stops, agent reports).
- **Turn structure:** the same path can be one message ("find Goa photos and make a collage")
  or spread over several turns.
- **Clarification:** missing required args (e.g. no album name) inserted as an ask-user turn.
